# bmo-drive

The file viewer as one service with its own API: this machine's drives, its Garage and the nodes'
volumes walked as places, what stands there read and changed, and the share links that hand one file or
folder to someone with no token. Beside the service the binary carries its command, `bmo-drive file share`,
its client and its harness plugin, the MCP server `bmo-drive mcp` with the `bmo-drive` skill. Every other
unit is reached through its API, as `docs/api.md` lists.

## Tests

The repository carries one test, the repository-wide personal-data check in `tests/personal_data.rs`
(`PERSONAL-DATA.md`), and runs it with `cargo test --test personal_data`. The behaviour tests are deferred:
they are written and run here once the minimal services stand on the new repositories, and until then the
build check, `cargo check --all-targets`, and the bundle's typecheck stand beside the one test.
`docs/inventory.md` lists the tests the old behaviour was held to.

`PERSONAL-DATA.md`, `korean-ledger.json`, `settings.toml`, `settings.local.toml.example` (the example of
the local settings a deployment gives) and `LICENSE`.

## The console plugin bundle

`client/` holds the Files screen and its file share page as a Nuxt layer on top of bmo-ui, packed as
`bmo-drive-client` and declared in `client/console-bundle.json` by bmo-ui's console plugin contract
(bmo-ui's `docs/console-bundles.md`): the bundle `drive`, its screens under `/files`, calling the service
`drive`. Its words stand in its own pack, `client/i18n/`, one file to a locale, under `drive.*`, with
`drive.error.<code>` for each refusal code of `docs/api.md`. A console extends it as it extends bmo-ui and
owes it bmo-ui itself at the version the bundle's peer names (a packed copy stands in `client/vendor/` for
the bundle's own install and typecheck) and a relay of the services its screens call: `drive`, and `node`
for the node list the screen reads from the node service.

The screen's types of the service's answers are generated from `docs/openapi.json` into
`client/shared/openapi.ts` by `bun run api`. The bundle's check is `bun install --frozen-lockfile && bun
run typecheck` inside `client/`.
